# 🧠 CogniCore: Veri Odaklı Bilişsel Antrenman Platformu
CogniCore, kullanıcıların zihinsel yeteneklerini geliştirmek üzere tasarlanmış, Büyük Veri (Big Data) ve topluluk analizleriyle desteklenen modern bir web uygulamasıdır. 

## 🎥 Tanıtım Videosu
Projenin canlı oynanış, arayüz ve sistem tanıtımını izlemek için tıklayın:
▶️ [CogniCore Demo Videosunu İzle](https://youtu.be/DPf1Lea5O-g)

## ✨ Özellikler
* 50.000 kişilik veri setinden elde edilen topluluk ortalamalarıyla "Karşılaştırmalı Zeka Profili".
* Asimetrik Dark Bento Box mimarisi ve Gündüz/Gece (Light/Dark) tema desteği.
* Framer Motion animasyonları ve özel yerel (local) SFX entegrasyonu.

## 🛠 Teknolojiler
React 18, Vite, Tailwind CSS, Zustand, Framer Motion
